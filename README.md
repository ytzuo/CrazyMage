# 失控法师 · 基础战斗原型

基于 TypeScript、Phaser 3 和 Vite 的浏览器基础战斗原型。

竞技场铺满浏览器窗口，去掉外围边框和侧栏；不展示标题、介绍或操作提示，保留暂停、重新开始、生命条、手机摇杆和右下角小地图。支持手机竖屏、横屏及安全区域，窗口缩放时画布和镜头同步调整。

地砖、法阵及装饰缓存为小纹理，避免每帧重新计算整张地图的矢量图形。暂停或失焦时停止渲染循环，继续后恢复；浏览器尺寸未变化时不重复调整画布。开发模式采样启动阶段的帧耗时，结果保存在游戏 canvas 的 `data-performance` 属性中，不增加界面文字。采样范围及限制见性能保障指南。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

在浏览器打开终端显示的地址（默认 `http://localhost:5173`）。手机与电脑连接同一网络后，访问启动输出中的 Network 地址。手机浏览器使用左下角虚拟摇杆。

```sh
npm run typecheck
npm run build
npm run preview
```

生产文件生成在 `dist/`，可以部署到任意静态文件服务器，支持子目录部署。

## 当前操作

- WASD：移动，斜向速度保持一致。
- ↑ ↓ ← →：朝对应方向发射火球，点按一次，按住连续发射；支持斜向组合及边走边攻击。方向键不会移动角色。
- 手机等以触屏为主要输入的设备显示左下角摇杆：拖动移动，拖出摇杆后仍可控制。通过粗指针且无悬停能力检测；电脑端隐藏，缩窄窗口不会显示。
- 暂停按钮、Esc、空格：暂停 / 继续。
- 回转箭头按钮：重新开始，回到中央、恢复满血并重置怪物和火球。
- 窗口失焦或切换标签页：自动暂停，点击继续探索恢复。

地图为 2400 × 1800，角色移动速度为 300 像素/秒。地图内圈限制角色活动，装饰暂不阻挡移动。顶部中央显示本局活动时长（分:秒），暂停和死亡时冻结，重开归零；死亡弹窗展示最终时长。小地图显示边界、中央法阵、角色亮点和怪物红点，随移动更新；击杀或重开后清理旧红点。小地图桌面宽 240 像素，手机通常宽 176 像素，不显示坐标、距离及施法计数。

## 范围

已实现竞技场、人物移动、方向键火球、追击怪生成、命中伤害、接触攻击、双方生命值、受击无敌与击退、死亡重开、小地图、手机摇杆、暂停及自适应布局。火球每 350 毫秒可发射一次，速度为 560 像素/秒，寿命 1.4 秒；暂停时冻结整个战斗。手机触屏模式自动向附近怪物发射火球。冰环、闪电、经验、升级、Boss、存档和结算尚未实现。

角色生命 200；追击怪生命 40，开局第一波 6 只，此后每 30 秒从竞技场四边刷新一波 6 只，上限 36 只，出生点避开角色附近。画面中间靠上放大显示当前波次和下一波倒计时，最后 5 秒变色提醒；暂停或死亡时停止计时，重开恢复第 1 波和 30 秒。满额时仅补充空余名额，不积压生成请求。火球伤害 20；怪物攻击预警 300 毫秒、伤害 10，角色受击无敌 900 毫秒。参数集中在 `src/game/config.ts`。

核心伤害与碰撞检查可在支持 TypeScript 类型剥离的 Node.js 中运行：

```sh
node --experimental-strip-types --test tests/combat.test.mjs
```

完整设计与当前验收条件见 [需求说明](docs/requirements.md)。
