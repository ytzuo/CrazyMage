# 失控法师 · 基础战斗原型

基于 TypeScript、Phaser 3 和 Vite 的浏览器基础战斗原型。

竞技场铺满浏览器窗口，去掉外围边框和侧栏；不展示标题、介绍或操作提示，保留暂停、重新开始、生命条、手机摇杆和右下角小地图。支持手机竖屏、横屏及安全区域，窗口缩放时画布和镜头同步调整。

地砖、法阵及装饰缓存为小纹理，避免每帧重新计算整张地图的矢量图形。暂停或失焦时停止渲染循环，继续后恢复；浏览器尺寸未变化时不重复调整画布。开发模式采样启动阶段的帧耗时，结果保存在游戏 canvas 的 `data-performance` 属性中，不增加界面文字。采样范围及限制见性能保障指南。

每个流派拥有专属大招，普通击杀充能，按 Q 或点击按钮释放。规则与验证见 [流派大招](docs/ultimates.md)。

四类怪物各有随机变种：死亡分裂、预警突刺、固定方向三连发、概率格挡。规则见 [怪物变种](docs/enemy-variants.md)。

## 启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

在浏览器打开终端显示的地址（默认 `http://localhost:5173`）。手机与电脑连接同一网络后，访问启动输出中的 Network 地址。手机浏览器使用左下角虚拟摇杆。

```sh
npm run typecheck
npm run build
npm run preview
```

生产文件生成在 `dist/`，可以部署到任意静态文件服务器，支持子目录部署。

## 当前操作

- WASD：移动，斜向速度保持一致。
- ↑ ↓ ← →：朝对应方向发射火球，点按一次，按住连续发射；支持斜向组合及边走边攻击。方向键不会移动角色。
- 手机等以触屏为主要输入的设备显示左下角摇杆：拖动移动，拖出摇杆后仍可控制。通过粗指针且无悬停能力检测；电脑端隐藏，缩窄窗口不会显示。
- 构筑按钮、U：查看最终攻击参数与获取记录；查看时暂停，关闭后恢复之前的暂停状态。升级选择完成后才能继续。
- 暂停按钮、Esc、空格：暂停 / 继续。
- 回转箭头按钮：重新开始，回到中央、恢复满血并重置怪物和火球。
- 窗口失焦或切换标签页：自动暂停，点击继续探索恢复。

地图为 2400 × 1800，角色移动速度为 300 像素/秒。地图内圈限制角色活动，装饰暂不阻挡移动。顶部中央显示本局活动时长（分:秒），暂停和死亡时冻结，重开归零；死亡弹窗展示最终时长。小地图显示边界、中央法阵、角色亮点和怪物红点，随移动更新；击杀或重开后清理旧红点。小地图桌面宽 240 像素，手机通常宽 176 像素，不显示坐标、距离及施法计数。

## 范围

已实现竞技场、人物移动、方向键火球、四类怪物混合生成、波次强度增长、命中伤害、接触攻击、双方生命值、受击无敌与击退、死亡重开、小地图、手机摇杆、暂停及自适应布局。开局选择火焰、冰霜、闪电流派之一；选择前冻结战斗，重开重新选择。火焰基础火球每 550 毫秒可发射一次，速度为 560 像素/秒，寿命 1.4 秒；暂停时冻结整个战斗。冰霜以近身冰环减速控场，闪电定向首击并连锁；手机触屏模式自动对有效目标施法。

已加入每完成一波抽取一次强化、暂停三选一、强化机会队列、构筑查看和获取记录。清空场上所有怪物后，下一波倒计时重置为 3 秒，强化已满时同样生效，本局时长继续独立累计；暂停时冻结，重开恢复初始 30 秒。火球可叠加增伤、多重、穿透、首次命中爆炸，最多 Lv.4；被动已实现移速、生命、护盾、冷却四种，最多装备三种，每种最多三级。冰霜有增伤、范围、寒意与回响强化；闪电有增伤、更多跳跃、距离与稳定传导强化。每局候选只包含所选流派和有效通用被动，详情见 [三流派设计](docs/schools-design.md)。拾取范围、异常状态被动、危险升级、Boss、存档和结算尚未实现。

角色生命 120；追击怪生命 40，开局第一波 6 只，此后基础每 30 秒从竞技场四边刷新一波，每波增加 2 只、单波最多 24 只，上限 36 只，出生点避开角色附近。画面中间靠上放大显示当前波次和下一波倒计时，最后 5 秒变色提醒；暂停或死亡时停止计时，重开恢复第 1 波和 30 秒。满额时仅补充空余名额，不积压生成请求。火球伤害 20；第一波追击怪攻击预警 300 毫秒、伤害 10，角色受击无敌 900 毫秒。波次数量与倍率上限位于 `src/game/enemies/difficulty.ts`，怪物属性与阵容位于 `src/game/enemies/roster.ts`，刷新间隔和场上总数上限位于 `src/game/config.ts`。

第 2 波加入快速脆弱小怪（绿色），第 3 波加入远程脆弱小怪（紫色），第 4 波加入大体型高血高攻怪（棕色）。远程怪先显示 700 ms 固定瞄准线再发射可躲避的弹丸，重型怪有 850 ms 圆形攻击预警；受击可打断。生命每波按基础值 +8%（最多 2.5 倍），攻击 +6%（最多 2 倍），速度 +2%（最多 1.2 倍），出生时固定。敌方弹丸最多 32 枚，寿命 3.2 秒，清场及重开会清理。

核心伤害与碰撞检查可在支持 TypeScript 类型剥离的 Node.js 中运行：

```sh
npm test
```

本地开发服务还提供 `/tests/runtime.html`（真实法术运行器、组合与回收检查）和 `/tests/ui.html`（真实清波、选卡与暂停流程检查）；点击检查按钮执行，测试页不进入生产构建。

完整设计与当前验收条件见 [需求说明](docs/requirements.md)。
