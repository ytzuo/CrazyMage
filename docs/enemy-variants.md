# 怪物变种

每次从地图边缘生成一只怪物时，有 25% 概率改为对应变种。类型的解锁波次沿用原规则：追击怪开局、快速怪第二波、远程怪第三波、重型怪第四波。变种沿用基础怪物的波次生命、伤害与速度增长，不额外叠加属性倍率。

| 基础类型 | 变种 | 行为 | 外观 |
| --- | --- | --- | --- |
| 普通近战 | 分裂怪 | 死亡在原位置分裂成两只小怪 | 青绿色双鼓包与纵向裂缝 |
| 快速 | 突刺怪 | 260 范围触发，550 ms 橙色直线预警，然后按锁定方向突刺 300 ms，冷却 1800 ms | 橙色尖冠与背部双箭纹 |
| 远程 | 连射怪 | 原有 700 ms 预警后，固定方向三连发，每发间隔 180 ms | 粉红色三水晶杖与领口标记 |
| 重型 | 盾甲怪 | 每次命中有 35% 概率格挡本次伤害，成功后 400 ms 内不再格挡 | 蓝灰大盾与额头金属护条 |

## 分裂与清波

分裂小怪体型为母体的 65%，生命 45%、攻击 60%、速度 115%，继承母体出生波次的数值快照。出生预警 350 ms，期间不造成伤害也不受击。小怪不会再次分裂。

小怪计入母体波次的剩余敌人数，必须全部击杀才获得该波强化。先登记新增小怪，再结算母体死亡，避免提前奖励。它们正常计入击杀数，并按击杀来源给大招充能。清空全部怪物后仍重置下一波倒计时为 3 秒。

场上怪物总上限仍为 36；母体死亡后若不足两个空位，本次不分裂，不积压出生请求。基础每波生成上限仍为 24，分裂会增加该波实际需要清理的数量。

## 攻击与控制兼容

- 突刺不追踪已移动的玩家，以线段碰撞检测冲刺路径，一次突刺最多造成一次接触伤害。减速降低突刺速度，受击或冻结取消正在蓄力或执行的突刺。
- 连射的三发共用蓄力时的瞄准方向，连发期间保留瞄准线，受击或冻结取消剩余连发。已发射弹丸继续飞行。
- 格挡有蓝色闪光和护盾环，不扣生命、不击退、不打断攻击。格挡也消耗该次火球命中和穿透次数，防止同一弹丸反复判定；首次命中爆炸仍可触发。格挡只抵挡伤害，冰霜减速与大招冻结仍可生效；冻结期间不能格挡。
- 暂停停止所有计时，重开销毁敌人和待执行动作，不使用网页定时器。

## 资源与交付

新增四张 128×128 缓存变种贴图，准备阶段在基础贴图上绘制形状标记，重开复用。没有逐帧生成纹理；预警沿用每只怪物原有的圈与瞄准线。格挡反馈沿用最多 96 个、最长 650 ms 的粒子系统；敌方弹丸仍最多 32 枚、寿命 3.2 秒。

按用户要求，本次不自行运行测试和浏览器试玩。旧运行器的基础行为检查固定随机源以排除变种干扰；实际页面检查按真实击杀数计算大招充能，适应分裂增加的击杀数。玩法、外观与性能由用户试玩验证。
