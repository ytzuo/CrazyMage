# 交互式敌人图鉴

入口为 [bestiary.html](../bestiary.html)。开发服务访问 /bestiary.html，生产构建同时输出游戏首页和图鉴，支持静态部署；图鉴可直接返回游戏启动页。

覆盖九种敌人、十八种形态：七种普通怪与对应变种，两位 Boss 与各自半血形态。目录支持按名字、攻击和机制搜索。演示内容按形态提供，支持普通/特殊形态切换、暂停、重播、半速、命中和两秒冻结；Boss 的七个招式改为舞台上方的独立按钮，普通与半血形态都可逐招查看。预警、出手、后续伤害与恢复阶段复用游戏实际战斗系统，单招播放完实际休息再重播，不跳到其他招式。拖动法师演示靶可以观察锁定与躲避。

机制演示包括母体死亡分裂、连续两次命中观察格挡与扣血、蓄力击杀转友军爆炸、祭司护盾破碎、同伴移出结界，以及 Boss 破甲露核和残影切线。文字区仅保留动作与攻击、关键机制。属性读取当前 enemySpec，观察波次与竞速/无尽模式决定生命、攻击和移速；半血形态以 40% 当前生命开始，属性栏仍展示该波最大生命。

界面保留名称、属性、演示操作与战斗说明，移除全部形态简介、“怎么应对”整栏、演示提示、数量汇总和页脚说明；Boss 招式说明只在战斗说明区显示，暂停状态统一显示“已暂停”。本次精简通过类型检查、生产构建及十八种形态切换、移动演示、搜索、暂停与继续检查。

## 演示布置与资源

图鉴通过独立适配层放置真实 EnemySystem 对象，没有修改游戏敌人、攻击或数值。为清楚展示，法师不会死亡，首招等待被控制，支援同伴固定站位；这些是演示条件，不是游戏新规则。攻击判定、预警时长、招式后续阶段和五秒 Boss 休息仍读取原运行器。普通怪会在 6.5–10 秒重播，单招 Boss 整套结束并休息后重播，移动近看只关闭攻击。

全页一个 Phaser.Game、一个 Scene 和一个 EnemySystem。单个演示最多四个敌人（主体及三位同伴；分裂后最多两碎片），一次只演示一个条目。切换、重播与场景关闭调用 reset，清掉敌人、部件、弹丸、区域、残影、保护与反馈；共享纹理复用。弹丸沿用 32 / 3.2 秒上限，战斗反馈沿用 96 / 650 ms；Boss 和支援效果保留原有全局预算及寿命，图鉴通常至多两切线或三魔核。

缓存地格纹理为 64×64；两个静态参照圆只初始化 Graphics 命令。十八个目录肖像由共享贴图一次性转为 PNG 数据 URL，不在逐帧路径生成。模型变换和战斗只推进活动时间；阶段文字按变化更新、最多每 200 ms 检查，无网页定时器或 Tween。

暂停、窗口失焦和页面隐藏执行 game.pause + loop.sleep，需要点击继续恢复；尺寸观察仅在宽高变化时 resize，暂停时只补一帧以显示新的尺寸或条目。场景关闭移除 ResizeObserver 和窗口监听，返回缓存页面保持暂停。诊断和巡检模块只在开发模式加载，生产不展示检查工具；图鉴文字不加入游戏战斗界面。

## 演示分类调整

- 普通追击、迅捷、远程、重型和咒印投手：移动与攻击，不显示机制入口和机制说明栏，原有攻击规则并入攻击说明。
- 突刺、连射、三重咒印、两种祭司：移动与机制，攻击与机制说明合并，不重复显示攻击演示。
- 分裂怪、盾甲怪、两种爆核：移动、攻击、机制，分别演示独立的分裂、格挡与友军爆炸；专用触发按钮仅出现在机制演示。
- 两位 Boss：移动与逐招攻击，删除重复的机制回放；露核、残影与半血规则保留在文字说明中。魔核守卫四招、裂隙织主三招始终直接可点，点击后从移动切到攻击，播放整套真实招式与恢复窗口。说明随所选招式及半血形态更新。

切换形态时，如果当前演示不适用，自动切换到该形态可用的攻击或机制；移动模式保留。分类函数复用于开发场景检查，新增入口只在选择变化时更新 DOM，没有改动战斗、循环、资源预算或尺寸生命周期。最新记录见 [分类与招式验证](bestiary-revision.json)：50 个场景通过，逐一检查 18 种形态的显示状态；生产页验证普通/半血共 14 个 Boss 招式按钮，手机 390×844 无横向溢出。类型检查与生产构建通过。本次不重新作运行性能结论，原持续巡检仅代表初版采样。

## 紧凑布局调整（2026-10-04）

桌面图鉴改为演示画面与机制说明并排，命中、冻结和机制按钮收进演示区底部，减少查看当前敌人时的纵向跳转。窄屏仍保持单列，并将操作按钮放在演示画面之后。

使用无头 Chrome 逐一检查 18 种敌人，覆盖 1280×720、1440×900、1024×768、740×390 和 390×844。共 45 个视口与敌人组合无横向溢出；三个桌面尺寸的主内容区不需要滚动，演示画面最小高度不低于 175 像素。命中、冻结、暂停和恢复操作通过，控制台无页面异常。该检查用于布局与交互，不代表 GPU 或持续运行性能。
