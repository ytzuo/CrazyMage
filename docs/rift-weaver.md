# 裂隙织主

第二个 Boss 已实现，待玩家试玩。第 10、20 波登场，与第 5、15 波的魔核守卫交替；无尽继续每五波交替。两种 Boss 都使用骷髅血条与小地图骷髅，击杀充满 Q，同波全部清完才发普通与大招强化。

## 外观与属性

薄面具、空心紫色魔核、四只细臂和三枚悬浮碎片。漂浮按活动时间推进，碎片延迟跟随移动，蓄力张开手臂；半血以下面具开裂，显示六臂。始终可受伤，没有瞬移免疫；普通命中保留蓄力，冻结取消整套攻击。

基础生命 675（同波守卫约 75%）、攻击 26、速度 76、半径 42、施法距离 720；按出生波次与模式应用成长。出生预警后先休息 1800 ms，再按“换位 → 切线 → 回收魔核”循环；远处接近，近处后退，平时维持约 250–390 的距离。

## 招式与反击机会

| 招式 | 规则 | 空档 |
| --- | --- | --- |
| 裂隙换位 | 距玩家约 300 的固定落点，轮廓预警 800 ms 后瞬移；墙边选有空间的候选点。不造成接触伤害 | 落地原地停顿 800 ms；半血 1200 ms |
| 织界切线 | 两条固定平行线，两端符印连接虚线预警 1000 ms，随后形成宽 36、长至多 600 的伤害带，持续 1400 ms；墙边截短 | 预警期间可穿过，两线中心间距 180 |
| 魔核回收 | 三枚魔核沿锁定扇形路径、至多 420 距离飞出；路径预警 1000 ms，2000 ms 飞出、末端停顿 550 ms、2000 ms 原路返回 | 慢速，轨迹常驻，返程轨迹变粉紫色；每条腿线段碰撞，最多结算一次接触 |

**每套完整攻击结束后重新计 5000 ms 休息，半血保持相同间隔。** 休息不与招式时间重叠，长帧不吞掉新阶段的预警或往返停顿。

半血“断界形态”在瞬移原点留残影，锁定玩家脚下的一条额外切线，完整预警 1000 ms、生效 1400 ms，只释放一次，结束后消失。主身落地停顿更长，整套攻击等残影消失再开始 5 秒休息。其他招式保持相同预警。

## 资源与清理

- 每只新增十张部件 Image：六臂、三碎片、核心，普通隐藏两臂，半血复用。躯干复用 body；父容器拥有部件。
- 全场最多六套织主招式，开头预留整套名额，满额等待、不排队。每只最多两切线、三魔核、一落点轮廓、一残影；招式互斥。全场切线上限 12、魔核 18、轮廓 6、残影 6，动态图片合计最多 36（每线三张，每魔核两张）。
- 切线最长 2400 ms，魔核含预警最长 5550 ms，轮廓 800 ms，残影约 2400 ms；按活动时间推进，帧边界可延后一帧。冻结取消招式并释放名额，模型与休息时钟停止。
- 死亡、清场、重开与场景关闭由 EnemySystem.reset/BossCombat.remove 回收部件、预警、符印、路径、魔核、残影与状态。共享纹理保留；新增 11 张缓存纹理、146304 源像素，只初始化生成，无逐帧绘图、Tween、网页定时器或生产 DOM 更新。
- 共用 72 敌人容量；守卫独立保留 24 区域预算。祭司护盾、结界不覆盖两种 Boss；冰霜冻结都保留 Boss 的 35% 时长。
