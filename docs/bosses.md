# 周期 Boss：魔核守卫

每五波随普通怪物从地图边缘出现一只 Boss，独立的黑曜石浮空躯体、熔岩核心、悬浮双臂和王冠，头顶以骷髅头标记代替名称，保留血条，小地图沿用红点。

近战预警使用橙色刻度环与边缘渐变；远程连爆使用红色符文六边形与中心定位标记。锁定区域不移动、不缩放，边界对应实际伤害半径；爆发时切换成带裂纹和热光的冲击纹理，240 ms 内淡出。骷髅与范围材质统一缓存，不依赖字体中的符号字符。

Boss 波生成后，到下一波的默认倒计时为 45 秒，普通波仍为 30 秒；清空全场仍重置为 3 秒，选卡、暂停与失焦冻结倒计时。延长的是 Boss 已经登场的这一波，不是登场前的等待。

每完成一波（包括 Boss 波），玩家恢复 15 点生命，不超过当前上限；击杀 Boss 但同波小怪未清完时不回血。选普通强化和大招强化不会额外触发回血。回血沿用波次完成的去重结算，不新增计时器和特效对象。本轮按用户要求未运行测试、构建或浏览器试玩。

- 基础生命 900、攻击 30、半径 54、速度 64，随出生波次应用现有倍率，生命最高 2250。普通伤害不会打断 Boss 蓄力，击退极小；冰霜大招仍可冻结并受击处决。
- 近战：玩家进入 165 距离后，在 Boss 当前位置预警 900 ms，然后对半径 180 的地面造成伤害。玩家可提前离开圆形区域。
- 远程：距离不足 760 时，在玩家当前位置及两侧标记三处半径 80 的红色地面区域，1100 ms 后依次引爆，间隔 220 ms。锁定后不跟踪，区别于远程小怪的直线弹丸。
- 半血后预警与攻击间隔缩短为原来的 75%。所有攻击按活动游戏时间推进，暂停冻结。
- Boss 击杀无论由普通法术还是大招造成，都将大招能量补满；仍只结算一次击杀。
- Boss 计入所属波次的实际怪物数量；击杀 Boss 不能提前完成尚有小怪的波次。清完同波全部怪物后，先领取仍可获取的普通强化，再额外选择一次本流派大招强化；普通构筑满级也不会阻止大招奖励。多波重叠按各自所属波次结算。

普通怪最多占用 35 个位置，保留一格给 Boss；总敌人上限仍为 36。下一波为 Boss 波且已经满额时，倒计时停在零并等待名额，本局活动时长继续统计，不积压 Boss 请求。每只 Boss 同时最多一组攻击、三处预警；爆发后的圆形区域保留 240 ms 作为命中反馈，死亡、冻结、重开与场景关闭清理预警。

本轮按用户要求未运行测试、构建或浏览器试玩，数值与手感由用户试玩确认。

小地图中 Boss 使用浅金色骷髅标记，尺寸大于普通怪物红点；位置随 Boss 移动，死亡和重开时移除，不显示名字。
