# 魔核守卫：重型战争傀儡

每五波从地图边缘随小怪出现一只守卫。宽肩、粗壮双腿、不对称石拳与符文护臂围住胸口魔核；行走左右承重，蓄力收拳或抬脚，重招结束后胸甲向两侧打开。半血后肩甲破碎、身体出现熔红裂纹。血条和骷髅标记上移，避免遮住头部；小地图仍用浅金骷髅标记。

基础生命 900、攻击 30、半径 54、移动速度 64，继续按出生波次与模式应用成长。平时所有攻击正常造成伤害，不增加护甲免疫；普通受击保留蓄力，冻结可以取消攻击。原有 Boss 击杀充满 Q、波次结算与强化奖励保留。

## 攻击与节奏

出生预警结束后先留 1.8 秒活动时间再开始首招。近处（210 以内）交替横扫和重踏；远处（760 以内）交替地脉连爆和冲撞。锁定后不追踪玩家，攻击期间停下或沿既定路线冲撞。

| 招式 | 预警与判定 | 半血变化 |
| --- | --- | --- |
| 重拳横扫 | 1100 ms 预警；锁向 120°、半径 180 的扇形，侧后方安全 | 再补一次转过 60° 的横扫，独立保留完整 1100 ms 预警 |
| 魔核重踏 | 1300 ms 圆形预警、半径 180；落脚后沿锁定方向及两侧 60° 各亮一条长 290、宽 50 的裂纹，1000 ms 后爆发 | 保留相同预警，不缩短躲避时间 |
| 锁向冲撞 | 1300 ms 路线预警，随后最多 1100 ms 冲撞，最长 520；墙边预先截短路径，减速可缩短实际位移；沿移动线段检查接触，每次冲撞最多结算一次接触 | 冲撞结束后追加一次半径 180 的重踏，完整预警 1300 ms |
| 地脉连爆 | 沿锁定方向由近到远排列三个半径 80 的落点，首段 1400 ms，后续相隔 450 ms；落点锁定后固定 | 四个落点，各自保留预警 |

攻击结束以最后一段伤害或冲撞结束为准，随后 **至少休息 5000 ms** 才能开始下一次蓄力，半血后同样保留 5000 ms。休息前 1800 ms 原地露核，半血时延长为 2200 ms；期间伤害统一乘 1.3，普通攻击、E、Q、持续与派生伤害都通过同一伤害入口。露核结束后继续接近玩家，但剩余休息时间仍需走完。

后续横扫、裂纹与冲撞后的重踏只在前段结束时创建；长帧不会吞掉它们的预警。活动时间为零不会推进状态；暂停、失焦与冻结不累计攻击或休息时间。

## 生命周期与资源预算

- 守卫仍计入 72 敌人容量，每只新增七张 Image（两腿、两臂、核心、两片胸甲），躯干复用原 body。随父容器销毁；BossCombat 在死亡、重开和场景关闭释放对应状态，冻结仅取消攻击、保留模型。
- 每只同时最多四张地面预警/反馈；全场最多预留 24 个区域，预算满时等待，不积压攻击队列。预留包含后续攻击及最多 300 ms 的反馈，回收后再释放名额。未使用网页计时器、Tween、逐帧纹理绘制或生产界面文字。
- 新增 16 个缓存纹理键、244224 源像素；现有完整 Boss 贴图换为新模型，完整普通/半血模型与活动部件共用绘制来源。纹理仅初始化生成，重开复用。
- 冻结取消预警和冲撞，休息计时冻结；普通受击同步各部件闪白，不取消 Boss 攻击。死亡、清场、重开和场景关闭移除区域、部件与状态。

Boss 波到下一波默认 45 秒，普通波 30 秒；清空全场仍为 3 秒。普通怪预留一个 Boss 名额，Boss 波满场时延后推进。击杀 Boss 不提前结算同波小怪，清完同波才回血 15 并发放普通与大招强化。

开发入口：[守卫预览与检查](../tests/guardian-runtime.html)。行为覆盖锁向躲避、横扫后方安全、冲撞线段碰撞、后续完整预警、5 秒休息、露核增伤、半血组合、冻结与死亡结算、24 区域预算及十次重开回收。性能采样与压力运行记录见 [守卫验证记录](guardian-verification.md)，原始数据见 [采样数据](guardian-performance.json)。未覆盖手机真机、GPU 完成时间及完整一局的三流派平衡。
