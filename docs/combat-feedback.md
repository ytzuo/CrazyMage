# 战斗与选择反馈

本次打磨开局流派、强化、清波与战斗特效，保持 WASD 移动、方向键施法、清波一次强化、清空三秒刷新和已有伤害数值。

- 开局卡片用法术色、圆形符印、聚焦边框和短暂入场区分火/冰/电。选择成功后提示法术就绪，并在角色处释放对应颜色光环。
- 强化卡片显示流派符号和四级进度，保留实际参数预览与查看构筑入口。清波完成在选卡标题确认，强化成功显示所选升级名称并释放成长光环。
- 没有待选强化的清场也显示清空提示；倒计时最后三秒短暂缩放。提示只有一条，新事件替换旧事件，不积压消息。
- 施法起手闪光、命中碎光、按怪物颜色消散、近战/远程出手与清场扩散圈只负责视觉；不影响伤害、攻击判定、死亡与奖励。
- 新特效最多 96 个 Image，寿命最长 650 ms，达到预算时释放最旧特效。纹理只在准备时缓存，更新仅处理位置、缩放、旋转与透明度；重开/场景退出由怪物系统一并清空。暂停沿用活动游戏时间，粒子不会在暂停期间消散。
- 网页提示不创建计时器，动画结束回收；暂停时冻结提示与倒计时动画，重开立即清空，热更新解除监听。卡片短暂动画不影响游戏时间；减少动态效果偏好关闭卡片与倒计时运动。

开发检查见 [法术运行页](../tests/runtime.html) 和 [界面检查页](../tests/ui.html)。
