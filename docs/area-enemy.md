# 远程范围小怪：咒印投手

第 4 波开始，每七个普通怪名额的第七个生成咒印投手；保留其他类型与 Boss 的生成规则，不额外增加每波总数量。外观为蓝紫斗篷、悬浮晶球和环形头饰，不使用普通远程怪的法杖；没有变种。

基础生命 32、攻击 14、速度 62、半径 18，沿用现有波次增长。距玩家 620 内蓄力，在玩家当前位置标出半径 70 的紫色范围，1100 ms 后引爆，冷却 3200 ms。落点锁定后不追踪玩家；同一次攻击只结算一次伤害。不同于普通远程怪的直线弹丸和 Boss 的三处连续爆发。

蓄力期间不移动，受击、冻结或死亡会取消该落点。冷却期间靠近或后退，与玩家保持距离；出生仍有 500 ms 安全预警。小地图使用红点、计入原波次清理与回血奖励。

全场最多 12 个落点，包括命中后 300 ms 淡出的裂纹反馈；每只投手最多一个。满额时等待名额再开始蓄力，不生成无预警伤害。区域材质复用敌方缓存纹理，活动时间推进，暂停冻结，击杀、清场、重开和场景关闭回收。投手静态贴图 128×128，仅初始化创建一次。

按用户要求，本轮未运行测试、构建或浏览器试玩。
