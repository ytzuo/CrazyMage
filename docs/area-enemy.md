# 远程范围小怪：咒印投手

第 4 波开始，每七个普通怪名额的第七个生成咒印投手；保留其他类型与 Boss 的生成规则，不额外增加每波总数量。外观为蓝紫斗篷、悬浮晶球和环形头饰，不使用普通远程怪的法杖。新增三重咒印变种，使用三颗粉、紫、青晶核和三叉冠饰。

基础生命 32、攻击 14、速度 62、半径 18，沿用现有波次增长。距玩家 620 内蓄力，在玩家当前位置标出半径 70 的紫色范围，1100 ms 后引爆，冷却 3200 ms。落点锁定后不追踪玩家；同一次攻击只结算一次伤害。不同于普通远程怪的直线弹丸和 Boss 的三处连续爆发。

蓄力期间不移动，受击、冻结或死亡会取消该落点。冷却期间靠近或后退，与玩家保持距离；出生仍有 500 ms 安全预警。小地图使用红点、计入原波次清理与回血奖励。

三重咒印沿用普通变种概率：第 4 波为 31%，每波加 2 个百分点，最高 80%。一次施法分别在 0、450、900 ms 锁定玩家当时所在位置；每个落点独立预警 1100 ms，通常在 1100、1550、2000 ms 爆发，最后反馈于 2300 ms 回收。锁定后不追踪，伤害与半径沿用普通投手。整组蓄力期间停步，受击、冻结、死亡、清场、重开取消剩余全部落点。异常长帧每次最多新增一个锁定，并保留其完整预警，不补发无预警爆炸。

全场普通与三重咒印共用 12 个落点名额，包括尚未显现的预留图像和命中后 300 ms 的反馈；每只投手最多一组。三重施法先一次预留三个名额，余量不足时等待，不生成半组攻击。区域材质复用敌方缓存纹理，活动时间推进，暂停冻结，结束或取消时统一销毁。新增一张 128×128 静态贴图（16384 源像素），初始化创建一次。
