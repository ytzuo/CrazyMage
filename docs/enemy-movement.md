# 小怪移动动作

2026-10-02。迅捷、重型、爆核及其突刺、盾甲、连爆形态使用独立左右脚，脚步随实际移动距离推进；迅捷步频更快、重型踏步更慢，爆核为短步摇摆。躯干起伏与双脚错开，腿的上端藏在躯干后，避免迈步时关节断开；盾牌仍随身体，不随脚摆动。追击怪增加轻微摇摆，远程和祭司移动时增加起伏。

每只怪物使用不同初始相位，避免整群同步踏步。停步约数百毫秒内收势；减速同步降低步频；朝向跟随实际移动，纯竖向保留朝向。击退不推进步态，突刺、蓄力和攻击使用原有姿态，冻结保持当前步态。碰撞半径、移动速度、攻击锁定方向、伤害和预警时点保持原规则。

## 缓存与回收

六种有腿形态新增 18 个缓存键：六张 128×128 躯干，十二张局部腿图。共 111608 源像素（不含原有模型）；只在准备阶段生成，重开复用。原始整身贴图仍供静态模型预览使用。

每只有腿怪物增加两个 Image，全场受 72 怪物容量约束，最多 144 个腿部对象，生命期与其敌人一致；死亡、清场、重开、关闭时随父容器销毁。每帧仅计算有界相位和变换、同步受击/减速/冻结颜色；没有逐帧绘制、DOM 更新、Tween、网页计时器或新增事件监听。血条、预警与判定继续使用实体位置。

## 追击怪补充（2026-10-02）

普通追击与分裂怪改为可见双腿和两侧手爪，接入既有步态，现共八种有腿形态。新增六个缓存键与 38144 源像素；每只仍最多两腿，全场 144 条腿上限不变。新模型、检查与可比采样见 [追击怪外观](chaser-art.md)，以上旧采样保留为此前六种形态的记录。
