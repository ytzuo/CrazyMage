# 升级选项卡固定尺寸

升级选项卡采用统一高度：桌面 410px、手机竖屏 236px、紧凑横屏 320px。每行列宽等分，卡牌正面、背面及翻转容器共用同一高度；短描述不再缩小卡面。描述区域占据剩余空间，过长时可滚动，底部选择入口保持对齐。

2026-10-04 验证：类型检查和生产构建通过。在 Codex 内置 Chromium 中，使用实际 BuildPanel 渲染短文案的“烈焰凝聚”、较长的“回旋焰弹”和无尽模式“冲击爆炸”，测量三张卡片尺寸：

| 浏览器视口 | 三张卡片宽度 | 三张卡片高度 |
| --- | --- | --- |
| 1280×720 | 272.66px | 均为 410px |
| 390×844 | 308px | 均为 236px |
| 740×390 | 约 211.33px | 均为 320px |

以上文案均无卡面内部溢出，横屏描述完整容纳。竖屏通过既有面板滚动查看后续卡片。此改动只调整 CSS，不改变战斗循环、资源预算或翻牌持续时间；未测量 GPU 合成性能或手机真机表现。
