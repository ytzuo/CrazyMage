# 《失控法师》攻击升级与组合设计

普通清波候选加入当前流派的 E 小技能强化：威力、范围、充能速度，每条三层且可兼容。与基础法术、被动共用一次三选一，基础法术有候选时仍保底一项；不占法术等级或被动槽。普通法术满级后小技能仍可成长，构筑页以“小技能强化”收藏卡显示，Boss 的额外大招强化保持独立。规则详见 [流派小技能](school-skills.md)。

## 周期 Boss 与额外强化

每五波出现 Boss，击杀后补满大招能量；清完 Boss 同波的小怪后，保留普通强化并额外选择一次本流派的大招强化。三个流派各有威力、范围与特色三条路线，特色分别增加火墙轮数、延长冰块冻结、增加追猎落雷轮数。每条三层，可同时叠加，不占法术等级与被动槽；普通强化满级不阻止大招成长。构筑页沿用简洁卡牌，标注“大招强化”与叠加次数。详细行为见 [流派大招](ultimates.md)。

当前实现开局火/冰/电三选一、对应流派法术和普通升级、清波奖励队列、构筑查看与四种通用被动。用户最新要求替代原先从火球开局、升级中解锁其他法术的方案；本局只走所选路线，重开重新选择。具体数值和法术行为见 [三流派设计](schools-design.md)，实现职责见 [升级兼容架构](upgrade-architecture.md)。

## 选择与成长

普通攻击等级上限统一为 8，现有四条模块的上限合计七次强化（2 + 2 + 2 + 1），可完整组合；每条模块的层数和战斗对象上限保持不变。E/Q 强化仍独立，大招随基础法术等级获得的伤害加成继续在 Lv.4 封顶。

每个流派初始 Lv.1，最多 Lv.8，允许选择 7 次法术普通强化。同一流派的不同模块兼容，重复选择提高模块层数；升级保留已获得能力。每完成一波实际生成的怪物，获得一次暂停三选一；候选只来自本流派和有效通用被动，有法术候选时保底一项。不抽其他流派、满级卡或第四种被动。

基础波次间隔 30 秒，清空场上全部怪物后重置为 3 秒，满构筑无强化时也生效。多波交叠分别结算奖励，场上还有其他波怪物时不重排倒计时。多个完成奖励排队，全部选完才恢复计时，选卡本身不重置倒计时。重开清空已完成波次、历史和待选奖励。

| 流派 | 强化路线 | 自然组合 |
| --- | --- | --- |
| 火焰 | 增伤、多重、穿透、首次命中爆炸 | 多枚弹丸各自穿透，首次命中溅射清群 |
| 冰霜 | 增伤、范围、寒意、回响 | 大范围减速怪群，延迟回响再次命中并刷新寒意 |
| 闪电 | 增伤、跳跃次数、距离、稳定传导 | 扩大首击/连锁距离，更多跳跃同时保留更高伤害 |

被动暂保留移速、最大生命、护盾、施法冷却四种，最多装备三种，每种三级。拾取范围因无经验掉落而不入池；异常状态被动和危险能力暂不提供。

## 构筑查看与强化预览

HUD 显示本流派法术及等级，U 或构筑图标打开详情，显示流派、大招效果和已获得的强化收藏卡，不展示战斗数值、获取时间或波次。初始记录根据选择显示火球、冰环或连锁闪电，不算强化。选卡界面可查看构筑后返回，不能漏选或消耗奖励。

强化卡片只显示名称、下一等级和一句核心效果，不再列出所有参数或前后数值。多重火球与寒潮回响仍提示单次威力降低，避免隐藏取舍；具体数值由战斗参数维护，不在构筑查看中展示。卡片采用流派配色、符文图案与双层边框，出现时依次从卡背翻开；动画不改变生命、构筑、候选随机序列或冷却。查看、选卡、开局选择、失焦、暂停和死亡均冻结游戏；关闭详情保留之前的暂停原因。

## 兼容与结算

- 数值从基础参数计算，同类加成相加，再应用明确倍率和上限；强化顺序不影响最终结果。
- 火球多重伤害系数只应用一次，每枚保留穿透；每枚首次直接命中爆炸，之后穿透不再爆炸；同次施法同目标最多一次溅射，派生伤害不递归。
- 冰霜回响保留施放快照、原施放位置与减速参数；每次脉冲每个敌人最多一次命中。每个敌人只有一个减速计时，取较强强度并刷新，强度上限 75%。
- 闪电首击从前方锥形内寻找最近目标，后续在跳跃范围找最近未访问目标；每次连锁最多 7 个不同目标，不在单体上重复跳跃。没有首目标时不消耗攻击机会。
- 所有伤害经同一怪物生命与死亡入口，怪物死亡和所属波次完成只结算一次。已有火球和等待中的回响保留旧参数，后续施法使用新构筑；冷却强化保留周期进度。

当前不提供跨流派法术混搭。未来若加入危险升级，必须保留普通能力、有明确预警与代价、可主动拒绝；不能以无效卡或空白候选强迫选择副作用。火区、危险停顿、配方法术进化和结算流派卡留到后续迭代。

## 验证与边界

对象上限、回收路径和性能要求见 [性能保障指南](performance-guide.md) 与 [三流派设计](schools-design.md)。重点验证三路线实际攻击差异、对应候选过滤、参数预览一致、回响快照、连锁去重、冻结与重开、不同获取顺序、手机布局和资源回收。手机真机、GPU 和完整 6–8 分钟一局的验证不能由逻辑测试替代。

## 清波至选卡的流派过渡

清波生成强化批次后，先显示约 0.8 秒专属过渡，再依次翻开卡牌：火焰为余烬凝聚、冰霜为晶体与法阵凝结、闪电为雷光与电弧汇聚。过渡只属于当前强化批次，期间不显示可选卡；使用 CSS animationend 切换，不使用网页定时器或修改奖励。重开和切换批次移除旧节点，旧事件不能打开新批次。

战斗沿用待选奖励的暂停状态，下一波倒计时不推进。页面隐藏时过渡暂停；减少动画设置下以 1 ms 完成状态切换，直接选卡。过渡时主动打开构筑会结束该批次过渡，返回后直接展示选项。每个排队奖励各有自己的过渡；满构筑没有选卡奖励时不额外等待。

按用户要求，本次未自行运行测试、构建或浏览器试玩。
