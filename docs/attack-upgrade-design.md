# 《失控法师》攻击升级与组合设计

状态：清波奖励、升级队列、构筑查看、四种火球强化与四种被动已实现；冰环、闪电、异常强化、危险升级和结算仍待实现。本文同时描述后续目标，当前交付范围以 [需求说明](requirements.md) 为准。以下数值仍需试玩平衡，不能据原型验证宣称完整一局性能达标。

对应的模块职责、数据流、行为合成和命中去重方案见 [升级兼容架构](upgrade-architecture.md)。

## 1. 玩家获得什么

升级应同时改变攻击形态和战斗选择。玩家能够从单发火球逐步构建多弹丸、穿透、范围伤害，再通过冰环和闪电处理不同距离的怪物。每次选择保留之前已获得的能力，面板能解释最终攻击是怎样组成的。

首版仍限制为 3 种法术、6 种被动、最多装备 3 种被动。每种法术最多 4 级；危险升级另作为该法术的一个附加能力，每法术最多 1 个，不占被动槽。法术达到 4 级后，其他法术、被动和危险升级仍可提供成长。

不要求玩家记住指定配方。组合来自已有属性和状态规则，例如“更多火球 × 穿透更多敌人”“减速敌人 → 更容易命中”“冰环拖住密集怪物 → 闪电找到更多跳跃目标”。

## 2. 获得升级的循环

每完成一波实际生成的怪物，获得一次三选一强化。最后一只死亡后暂停整个游戏，选择完成后继续；部分击杀和波次计时到期都不触发强化。

基础每 30 秒刷新一波，成功选完强化后下一波倒计时重置为 3 秒，本局时长不受重置影响。怪物保存波次归属；多波交叠分别结算，奖励每波只发一次。若同一帧清空多波，强化机会排队逐次展示，每次成功选择都重置倒计时，全部选择完成后才恢复战斗并计时。满上限而完全没有生成的波次不奖励；部分生成时按实际数量判定完成。

查看面板不会产生强化机会。查看、选卡、失焦、暂停、死亡冻结所有战斗与波次时间；重开同时清空完成记录、待选机会和构筑历史。

升级节奏取决于实际清波速度；6–8 分钟内每完成一波才获得一个机会，数值与整体节奏需要试玩调试。当前取消经验触发，拾取范围被动退出候选；其余有效能力保留。

## 3. 查看自己获得的升级

### 战斗中

生命条附近增加一排紧凑的法术图标，显示已拥有法术及等级，例如“火球 3 / 冰环 1”。有危险升级的法术带橙色角标，闪电停顿时对应图标显示倒计时。不要把升级列表常驻铺在战斗画面上。

增加一个“构筑”图标入口；电脑可按 `U` 打开，手机点击图标。打开时暂停；如果打开前已经暂停，关闭后仍保持暂停。失焦后不能因为关闭面板自动恢复。升级选择尚未完成时，构筑查看作为选择界面的详情页，返回后继续选择。

### 构筑面板

| 内容 | 玩家看到的信息 |
| --- | --- |
| 法术 | 当前等级、已选强化、危险能力、当前伤害 / 弹丸数 / 冷却 / 范围等实际数值 |
| 被动 | 已装备的最多 3 种被动，各自等级和实际加成 |
| 生效关系 | 具体效果，例如“多重火球的每个弹丸都具有穿透”“冰环减速使闪电更容易连到怪群” |
| 升级记录 | 按获取顺序记录选择：时间、波次、名称、当时等级；开局火球标记为初始能力 |
| 副作用 | 持续显示危险能力的代价和应对方法，例如“火区也伤害自己；提前离开预警区域” |

数值显示最终结果。例如冷却被强化到 245 ms 时直接显示 245 ms，并能展开查看基础 350 ms 与被动减免。尚未实现的法术、未获得的升级不显示成已激活能力。

重开清空本局构筑与升级记录，恢复起始火球。结算流派卡读取同一份构筑数据，展示本局升级和危险能力，避免战斗面板与结算各自保存一套结果。

## 4. 三选一卡片怎样表达

每张卡片包括名称、类型、当前 → 选择后等级、具体变化、已有升级的关联，以及危险能力的代价。展示实际变化，不仅写“提升伤害”。

示例：

| 卡片 | 显示内容 |
| --- | --- |
| 多重火球 | 火球 Lv.1 → Lv.2；1 枚 → 3 枚；单枚伤害 20 → 13；保留已有穿透与爆炸能力 |
| 冰环 | 获得冰环 Lv.1；每 4 秒释放一次，减速周围敌人；和已有火球同时生效 |
| 危险爆燃 | 为火球附加危险能力；扩大爆炸并留下火区；火区预警后会伤害自己；已有移速可帮助撤离 |

三张候选必须不同，满级、已获得的唯一危险能力和第四种被动不能进入候选池。首次获得新法术时明确写“获得”，已有法术强化时写“强化”。危险卡用明确颜色、文字和图标标识，不能只靠颜色表达。

危险升级出现时，另外两个选项应为可用的普通升级。可用普通候选不足两个时不出现危险卡，不能逼迫玩家选择副作用。

## 5. 普通法术强化：选模块，保留旧模块

开局火球为 Lv.1。获得新法术时也是 Lv.1。每次选择该法术的普通强化，总等级加 1，因此每种法术最多选择 3 次普通强化。

同一法术的不同强化可以共存；重复选择同一强化提高其层数。表中的“层数上限”还受到法术总等级上限限制。例如火球可以选择两次多重、一次增伤达到 Lv.4，也可以选择多重、穿透、爆炸各一次达到 Lv.4。

### 火球：定向攻击的主体

保留基础伤害 20、冷却 350 ms、速度 560 像素/秒、寿命 1.4 秒。电脑方向键决定瞄准方向，斜向组合和边走边攻击继续可用。手机自动选择射程内目标。升级不改变基础瞄准方式。

| 普通强化 | 首次效果 | 重复效果 / 上限 |
| --- | --- | --- |
| 灼热增幅 | 直接命中伤害 +30% | 最多 2 层；按基础伤害累计，最终 +60% |
| 多重火球 | 每次 1 枚变为 3 枚，围绕瞄准方向扇形发射；每枚使用直接伤害的 65% | 最多 2 层；第二层变 5 枚，65% 系数不再次降低 |
| 穿透火球 | 每枚可穿过额外 1 只敌人 | 最多 2 层；最多命中 3 个不同敌人 |
| 冲击爆炸 | 每枚火球首次命中时产生半径 80 的爆炸，对周围其他敌人造成该弹丸直接伤害的 35% | 最多 1 层 |

穿透和爆炸同时拥有时：第一次命中产生爆炸，弹丸继续飞行；后续穿透命中只造成直接伤害。这让两种能力都保留，同时限制爆炸数量。

多重弹丸可以分别命中同一敌人，因此靠近并准确瞄准有更高收益。每枚弹丸对同一敌人只能直接命中一次；同一次施法对同一敌人最多造成一次爆炸溅射。爆炸不包含触发它的直接命中目标，减少自动重复伤害。

### 冰环：周期性近身控场

获得后自动每 4 秒释放，半径 140、伤害 6，使敌人减速 25%，持续 1.5 秒。不增加键盘操作，不替代火球。

| 普通强化 | 每层效果 | 层数上限 |
| --- | --- | --- |
| 扩大冰环 | 半径按基础值 +35% | 2 |
| 急速寒潮 | 本法术冷却按基础值降低 15% | 2 |
| 持续寒霜 | 减速持续时间 +0.5 秒 | 2 |
| 凛冬冲击 | 伤害 +6，减速增加 10 个百分点 | 1 |

重新施加减速取较强强度，并刷新对应持续时间，不能将数次冰环的减速比例直接相加到无法移动。精英和 Boss 的减速限制在对应敌人实现时单独定义。

### 连锁闪电：密集目标清理

获得后自动每 2.5 秒寻找附近敌人，首个目标距离最多 360；基础伤害 12，随后在 180 范围内跳跃额外 2 次，总共最多 3 个目标；每次跳跃伤害乘 0.8。没有目标时不消耗这次攻击机会，也不积攒连发次数。

| 普通强化 | 每层效果 | 层数上限 |
| --- | --- | --- |
| 更多跳跃 | 额外跳跃次数 +2 | 2；单次最多 7 个目标 |
| 电能增幅 | 伤害按基础值 +30% | 2 |
| 延伸电弧 | 首目标与跳跃距离按基础值 +30% | 1 |
| 稳定传导 | 每跳保留系数 0.8 → 0.9 | 1 |

同一次闪电不重复访问已经命中的目标；单独一个敌人只受到首击伤害，不把多次跳跃全部集中到它身上。

## 6. 危险强化：附加能力与明确代价

建议在活动战斗时间达到 120 秒，且对应法术达到 Lv.3 后进入候选池。每种法术最多一个危险强化，最多一次获取。等级、普通模块和被动继续保留；危险强化消耗一次升级选择，但不提高法术等级。

| 危险强化 | 获得的力量 | 代价、显示与应对 |
| --- | --- | --- |
| 危险爆燃 | 为火球开启爆炸；已有爆炸则直接强化其范围。没有普通爆炸时以半径 80 为基础，爆炸半径乘 1.8，保留 35% 溅射系数，并在首次命中处留下火区 | 火区先预警 600 ms，再持续 2 秒；对进入的敌人施加 2 秒灼烧，每 500 ms 造成该弹丸直接伤害的 20%。对仍在火区内的角色每 500 ms 尝试造成 5 点伤害。橙色虚线预警变实心火区，玩家可移动离开；自伤不使用敌人伤害加成 |
| 极寒领域 | 冰环减速至少达到 60%，保留范围、冷却和持续时间强化 | 角色移动速度乘 0.9，构筑面板显示最终速度；角色周围淡蓝外圈持续提示，移速被动可以弥补 |
| 超载释放 | 每第 4 次成功闪电施法变为超载，首击与跳跃伤害乘 2，额外跳跃 2 次，目标上限 9 | 超载后闪电停顿 1.2 秒，再开始下一轮正常冷却；闪电图标显示停顿倒计时。停顿仅影响闪电，火球、冰环和移动继续运行 |

危险爆燃自己提供爆炸，因此无需强制先获得普通爆炸；若先获得危险爆燃，之后选择普通爆炸不能重复解锁同一效果。首版将普通爆炸卡从该法术的后续候选中移除；已拥有普通爆炸的升级记录保留。

敌人留在火区内时刷新灼烧持续时间，离开后剩余灼烧继续生效；身上的火光与地面危险区分别显示。灼烧属于状态伤害，不再次产生爆炸或火区。重叠火区对角色使用统一受击保护；对敌人保留较高伤害的灼烧，每个伤害时间片最多结算一次，不创建多个独立灼烧计时器。

## 7. 六种被动及兼容方式

最多装备 3 种，每种最多 3 级。装备满时仍能强化已装备被动；新种类不再进入候选池。

| 被动 | 每级效果 | 与攻击组合的关系 |
| --- | --- | --- |
| 移动速度 | 基础移速 +8% | 调整攻击角度、近身散射后撤离、躲开自伤火区；同时保留极寒减速代价 |
| 最大生命 | 最大生命 +20，获得时恢复同样的 20 生命，不超过新上限 | 提高靠近怪群施放冰环的容错 |
| 护盾 | 护盾容量 +20；连续 10 秒未受伤恢复到容量上限 | 先吸收伤害，再扣生命；有效命中即触发受击保护，不能被同帧多次攻击瞬间耗尽 |
| 拾取范围 | 当前清波奖励不需要拾取，暂不提供 | 后续若增加其他掉落，再重新确定用途 |
| 施法冷却 | 所有法术基础冷却降低 10% | 强化所有已拥有法术，不缩短攻击预警、自伤预警、无敌或超载停顿 |
| 异常状态强化 | 敌人减速增加 5 个百分点，状态持续时间按基础值 +20% | 强化冰环控制和火区持续时间；不延长伤害对角色生效的时间，不增加自伤 |

异常状态被动仅在拥有冰环或危险爆燃后出现，避免开局获得暂时无效的升级。对火区延长的是敌人灼烧有效时间；角色危险区仍按原来的 2 秒显示并结算，因此表现需要区分地面危险和附着在敌人上的剩余灼烧。

## 8. 叠加规则与兼容关系

### 统一计算顺序

1. 从基础法术参数开始。
2. 累加普通模块的加成，得到弹丸数、伤害、穿透次数、范围和本法术冷却减免。
3. 累加被动加成；同类“基础值百分比”加成相加，不按选择顺序反复相乘。
4. 应用明确的倍率或代价，如多重单枚伤害 0.65、危险范围 1.8、极寒移速 0.9。
5. 应用玩法上限、命中去重与触发次数限制，生成面板展示的最终数值。

冷却公式为 `基础冷却 × (1 − 法术冷却减免 − 被动冷却减免)`。首版冷却下限：火球 150 ms、冰环 1.5 秒、普通闪电 1 秒；敌人减速上限 75%。达到下限的强化不进入候选池。面板显示当前数值和上限，避免选卡后没有实际收益。

### 兼容表

| 组合 | 如何同时生效 | 避免的问题 |
| --- | --- | --- |
| 多重 + 穿透 | 每个弹丸保留穿透次数 | 不把不同弹丸当作同一弹丸，漏掉有效命中 |
| 穿透 + 爆炸 | 首次命中爆炸，后续命中继续造成直接伤害 | 每次穿透都爆炸导致伤害与特效成倍增长 |
| 多重 + 爆燃 | 每个弹丸首次命中可形成火区，重叠时按统一规则结算 | 火区互相触发新火区 |
| 冰环 + 火球 | 减速提高瞄准和穿透命中机会，火球照常施放 | 冰环解锁后覆盖火球攻击 |
| 冰环 + 闪电 | 控制怪群保持跳跃距离，闪电独立冷却 | 同一闪电在少数目标之间无限往返 |
| 极寒 + 移速 | 先累计移速加成，再乘极寒代价 | 升级先后顺序影响最终速度 |
| 超载 + 冷却被动 | 缩短正常闪电冷却，保留 1.2 秒停顿 | 冷却堆叠完全抹掉危险代价 |
| 火区 + 异常强化 | 延长敌人身上的灼烧，保留原自伤参数 | 玩家强化状态后反而受到更高自伤 |

一只怪物无论被几种攻击同时击杀，只产生一次死亡、清波奖励与击杀记录。伤害事件区分直接命中、溅射、状态、反作用伤害；派生伤害不能递归产生同类派生事件。

## 9. 候选生成，让想法做得出来

先筛选可以生效的卡片，再带权重抽取。已有法术强化权重建议 3，新法术权重 2，已装备被动强化权重 2，新被动权重 1，危险卡权重 1；这些是调试起点。

- 有可用普通法术强化时，每次至少一个候选与已有法术有关。
- 前三次升级内，至少一次展示尚未拥有的冰环或闪电，给玩家转向机会。
- 同一张卡在一次三选一中不重复；危险卡每次最多一张。
- 高度相关的组合提高权重：拥有多重时提升穿透的权重，拥有冰环时提升闪电或异常被动的权重；不保证必出。
- 记录最近未选的卡，适度降低连续重复展示概率；被拒绝的危险卡降低接下来两次的出现权重。
- 若少于三种有效升级，展示实际有效数量；所有项目都满级时停止生成升级选择，避免空白弹窗或强制危险选择。

每次选择后按当前构筑重新计算下一组候选，不能沿用升级前生成的候选导致满级或重复危险卡出现。

## 10. 三条可形成的成长路线

| 路线 | 早期 | 中期 | 后期结果 |
| --- | --- | --- | --- |
| 多重穿透流 | 火球 → 多重，获得扇形覆盖 | 穿透 → 灼热增幅，火球 Lv.4；选择冷却或移速 | 3 枚火球，每枚 16.9 直接伤害，可命中 2 个不同目标；保留移动与方向键瞄准，形成扇形穿透 |
| 控场电击流 | 获得冰环，降低近身压力 | 获得闪电，再强化冰环范围与闪电跳跃 | 冰环留住怪群，闪电清理多个目标；可选择极寒或超载继续强化，其他法术持续工作 |
| 绕圈放火流 | 多重 + 冲击爆炸，增加群体覆盖 | 移速 + 冷却，火球达到 Lv.3 后等待危险卡 | 危险爆燃保留多弹丸和爆炸，玩家沿怪群前方移动制造火区，并避开自伤预警 |

示例验证：多重穿透流的增伤为 `20 × 1.3 × 0.65 = 16.9`。若冷却被动达到 3 级，火球冷却为 `350 × 0.7 = 245 ms`。基础移速提高到 300 后，移速 2 级搭配极寒时为 `300 × 1.16 × 0.9 = 313.2 像素/秒`。无论升级获取顺序如何，最终值一致。

## 11. 实现约定与性能边界

配置分为基础法术、升级定义、当前构筑、升级历史和计算后的战斗参数。每次选卡重新计算参数；攻击时读取结果，不在逐帧循环中遍历全部升级描述或重建候选。

升级定义需要稳定 ID、归属法术 / 被动、层数上限、前置条件、候选权重、数值变化、事件行为和副作用说明。当前构筑保存各模块层数、法术等级、被动槽和危险能力；历史记录保存选择顺序、活动时间、波次与选后等级。界面与战斗均读取同一份计算结果。

命中需要同时携带施法 ID、弹丸 ID、伤害来源及已命中目标集合。闪电、爆炸和死亡事件分别去重。已有火球最长存活 1.4 秒，升级选择时旧弹丸保留发射时的伤害快照，新发射弹丸使用新构筑，避免飞行途中突然改变穿透记录。

当前弹丸上限 12 只适合单发火球。多重与冷却同时实现时，必须重新配置预算：5 枚 / 150 ms × 1.4 秒约 47 枚，建议先以 64 枚为上限进行实测。火区建议上限 24，相近同源区域合并并保留较高伤害；合并规则需与上面的重叠伤害一致。闪电目标上限 9；怪物仍受 36 只上限限制。

以上预算是待测建议。选卡不能让战斗因为旧上限而静默丢掉承诺的弹丸。超过预算时先优化存活时间、合并重复区域或调整升级参数，并同步卡片描述；仅视觉特效可合并或降低密度，不能随机丢掉实际伤害。波次账本仅保留未完成的波，强化队列不重复消费同一个完成奖励。

按 [性能保障指南](performance-guide.md) 验证最强组合、火区重叠、暂停、失焦、重开及完整一局的对象回收。当前的基础战斗性能采样不能直接作为组合系统的性能保证。

## 12. 分阶段实现和验收

1. **可获得、可查看：** 清波奖励、三选一、升级队列、构筑面板与历史。先实现火球增伤、多重、穿透和有效被动，确认已有升级始终保留。
2. **攻击方式有差异：** 加入普通爆炸、冰环和闪电，完成冷却、减速与去重规则，验证三条路线的操作体验。
3. **危险能力可理解：** 加入三个危险强化、预警、自伤、停顿提示和拒绝规则，验证组合与副作用。
4. **结算复用数据：** 流派卡展示升级、危险能力、伤害来源和时间，调节清波、候选权重与敌人节奏。

验收重点：

- 查看面板和历史准确反映本局选择，重开清空，关闭面板正确恢复之前的暂停状态。
- 多重、穿透和爆炸同时存在，新增法术不会覆盖火球；不同获取顺序产生相同最终参数。
- 升级前后的实际弹丸数、伤害、冷却与面板一致；超过上限的卡不会被无效抽到。
- 同一次施法、同一弹丸、重复跳跃、重叠火区与死亡奖励分别按约定去重。
- 危险能力有普通替代项，预警和代价可见；被动提高战斗能力时不偷偷放大自伤。
- 多级连升、手机点击、方向键按住时升级、失焦及死亡都不会漏选、连发旧输入或推进暂停计时。
- 最强组合在桌面和手机设备上完成性能检查，满足对象限制并正确清理；未测试项目明确记录。
