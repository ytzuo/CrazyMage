# 初始数值与攻击动作

初始生命从 200 降为 120；火球间隔从 350 改为 550 ms，冰环从 850 改为 1100 ms，闪电从 650 改为 900 ms。三类伤害数值、移速和敌人攻击时点保留，冷却被动仍按层数每层降低基础冷却的 10%。

角色成功施法时触发 280 ms 动作，身体前倾，独立法杖抬起、前推后回落，杖头根据流派发光；瞄准控制朝向，动作不锁移动、不延迟攻击，不在空目标闪电或冷却中空按时播放。重开清空动作。

敌人身体在原有攻击预警期间后撤、拉伸蓄力，出手后播放 230 ms 近战扑打或远程后仰；重型怪抬身与扑打幅度更大。只改变图片相对容器的姿态，容器位置、碰撞半径、瞄准锁定及伤害时点不变；受击打断同时取消动作，血条和预警不跟着倾斜。

计时全部使用活动游戏时间，暂停冻结，动作结束回到原姿态。角色增加一个法杖容器，敌人攻击复用已有图片，逐帧只更新变换；不新增特效生成、Tween 或网页计时器。相关浏览器验证入口为 `/tests/actions.html`。

小怪移动增加随实际位移推进的步态：迅捷怪、重型怪、爆核傀儡及其变种拆出左右脚，交替抬脚、摆腿并配合身体起伏；追击怪轻微摇摆，远程和祭司移动时起伏。移动朝向独立于攻击锁定方向，停步逐渐收势；减速降低步频，击退不计入迈步距离，突刺、蓄力和出手优先原有攻击姿态，冻结与暂停不推进。详细资源预算和验证见 [小怪移动动作](enemy-movement.md)。

开发检查见 [攻击动作测试](../tests/actions.html)。
