# 追击怪与分裂怪四肢

2026-10-02。缩短两种追击怪躯干，将双手移到两侧，露出膝部、小腿和三趾脚爪。分裂怪保留绿色核心、裂缝与缝合细节，膝部增加绿色标记；分裂后的子怪复用普通版本并沿用既有缩放。两种形态接入随位移推进的左右脚步态，攻击、冻结、判定与数值保持原规则。

新增六个共享缓存键：两张 128×128 躯干、四张 32×42 腿部图，共 38144 源像素。每只追击怪增加两个 Image，全场敌人上限仍 72，所有有腿敌人合计最多 144 个腿部对象，随父容器死亡/清场/重开/关闭销毁。缓存只在初始化生成，每帧仅调整位置、旋转、起伏及颜色。
