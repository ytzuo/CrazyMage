# 主题曲段落衔接

主题曲仍为 160 秒、96 BPM、4/4 拍、64 小节。六段章节起点继续为 0、20、60、80、120、150 秒。修改集中在伴奏连续性、音量交接和收尾和声，保留原主题动机及合成音色。

| 交界 | 调整 |
| --- | --- |
| 0:20 前奏 → 主题 | Boss 伴奏从 0:15 提前进入，取其结尾两小节，与前奏的 A 和声对齐；到 0:22.5 完成渐入。取消额外叠加的鼓填充。 |
| 1:00 主题 → 过渡 | 鼓组从 0:55 到 1:02.5 渐出；和弦与轻低音在交界前两小节接手，尾部加入 A–C 到 D 的旋律引导。过渡保留轻低音脉冲。 |
| 1:20 过渡 → 再现 | 从 1:15 提前引入与过渡末尾和声一致的伴奏，持续到 1:22.5 完成渐入；复用原鼓组的过门。 |
| 2:00 再现 → 高潮 | 将两段伴奏合为一次连续播放，在 Boss 原有循环边界接续；删除原本此处 280 毫秒淡出与 50 毫秒淡入造成的断口，高八度声部再逐步加进。 |
| 2:30 高潮 → 尾声 | 从 2:25 渐退原伴奏，在最后两小节写入 G 小调 → A7，再解决到尾声 D 小调；用 E–C# → D 旋律引导，调整持续音长度，避免旧和弦长时间压在尾声上。 |

音色处理继续使用原有低音、拨弦、铺底与打击乐。新增声部的尾音在完整曲目中延续，整体只在开头和结尾淡入淡出。主体伴奏的内部周期用于保持乐句连贯，主题曲本身仍为单次播放，最后不会折回开头。

## 验证与范围

在 macOS arm64、Python 3.9.6、NumPy 2.0.2 下生成。检查 44.1 kHz、16 位双声道 PCM 格式、160 秒长度、章节时间、无满幅削波、首尾为零、素材清单校验值、集中试听与主题原样本一致，以及 HTTP 分段读取。此前其他 WAV 均保持原校验值。

[验证记录](theme-transitions-verification.json) 保留五处交界前后各一小节（2.5 秒）的 RMS 数据与修改前对照。该数值描述导出文件的局部能量，并非人耳连贯度评分；段落强弱起伏仍是编排的一部分。未进行人工听音、浏览器播放、耳机或手机外放验证，实际衔接听感仍需试听。

重新生成（Python 3 与 NumPy）：

```sh
python3 tools/audio/render_theme.py
python3 tools/audio/make_preview.py
```

脚本只更新主题曲、五处衔接试听及其清单信息，不重写 Boss 循环或其他音效；清单版本使用递增上限，保留已有音效元数据。
