# 玩家受伤音效：少年与少女，各两个版本

独立试听素材，尚未接入游戏。打开[试听页](index.html)的「玩家受伤 · 四版本试听」，或直接播放[四版本对比](player_hurt_preview.wav)，顺序为少年 1、少年 2、少女 1、少女 2。

四个版本使用四段独立的 CC0 真人发声。通过小幅变速提调和柔和收减 110 Hz 附近的低频厚重感，往清亮、年轻的角色音色调整；保留原声的喉音和气息，不叠加合成元音或混响。少年／少女是角色音色方向，原录音者的实际年龄未知，自然度与年龄感需试听确认。

| 版本 | 输出时长 | 提调幅度 |
| --- | --- | --- |
| [少年 1](sfx/player_hurt_01.wav) | 0.220 秒 | +1.5 半音 |
| [少年 2](sfx/player_hurt_03.wav) | 0.245 秒 | +1 半音 |
| [少女 1](sfx/player_hurt_02.wav) | 0.293 秒 | +1.5 半音 |
| [少女 2](sfx/player_hurt_04.wav) | 0.321 秒 | +0.5 半音 |

变速同时提高基频、共振频率并缩短时长；幅度控制在 0.5–1.5 个半音。版本区别来自独立发声，不只是复制同一声音后变调。四个文件均为居中单声道、44.1 kHz、16 位 PCM，峰值约 −5.04 dBFS；峰值相同不代表感知响度完全匹配。

已有路径 `player_hurt_01.wav` 与 `player_hurt_02.wav` 分别对应少年 1、少女 1；新增 `player_hurt_03.wav` 与 `player_hurt_04.wav` 分别对应少年 2、少女 2。素材清单有 `voice`、`variant`、来源片段与变速参数，游戏中的形象选择和播放路由尚未接入。

男声两版来自 qubodup 的 `slightscream-01.flac` 与 `slightscream-03.flac`；女声两版来自 AuraVoice 同一录音的第三段与第二段。许可、作者、下载链接和原始校验值见[人声来源](sources/README.md)。仓库保存四个来源 WAV，重新生成不需要联网。

对比试听按[玩家无敌时间](../../src/game/config.ts)的 900 毫秒间隔播放四个版本，起始留白 250 毫秒，结束留白 350 毫秒，总长约 3.62 秒。每个文件短于 330 毫秒，不会在该排列中重叠；这是离线排布，尚未验证游戏触发。

检查环境为 macOS arm64、Python 3.9.6、NumPy 2.0.2。已验证男女各两个版本、四份独立来源、无满幅削波、首尾为零、重复生成一致、试听与速览样本一致、HTTP 分段读取、清单和来源校验值。数据见[验证记录](player-hurt-verification.json)。未进行人工听音、浏览器音频播放、手机外放或实战混音验证。
