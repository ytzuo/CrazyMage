# 失控法师 · 音频小样 V18

36 个音效、3 段循环音乐、一首 2 分 40 秒主题曲，以及一个 23.38 秒音效速览。音乐与 32 个音效由离线合成生成；四个玩家受击音效采用 CC0 真人录音剪辑，作者、许可与原始来源见[人声来源](sources/README.md)。36 个事件音效已接入游戏，包含 Boss 登场短乐句；主题曲、循环背景音乐与试听合集仍仅供独立试听。

- [音效速览](sfx_sampler.wav)：火焰、冰霜、闪电、受伤、护盾、清波、强化、Boss 登场依次排列，各段之间空出 0.48 秒。
- [火焰变体对比](fire_variants_comparison.wav)：5.31 秒，依次播放三种普攻与两种命中，声音之间空出 0.60 秒。
- [火焰 Q 三轮试听](fire_wall_rounds_preview.wav)：1.88 秒，按每轮 0.45 秒间隔播放三次单轮火墙音效。
- [法阵余光 · 主菜单](music/menu_loop.wav)：40 秒，16 小节，稀疏晶体音、缓慢和弦与低声脉冲。
- [试验失控 · 普通战斗](music/battle_loop.wav)：80 秒，32 小节，主题旋律、合成低音、琶音与轻打击乐。
- [魔核苏醒 · Boss 战](music/boss_loop.wav)：80 秒，32 小节，更密的节奏、低音五度与重鼓点。
- [魔核苏醒 · 失控法师主题曲](music/unstable_mage_theme.wav)：160 秒，64 小节，在原 Boss 编排上增加前奏、过渡、高潮与尾声。试听页提供六个段落跳转按钮，默认单次播放。

音乐共用 96 BPM、4/4 拍与 D 小调色彩，采用同一个四音主题动机。三段循环音乐保留完整小节长度；合成声音和扩散尾音跨越循环结尾后折回开头，不使用首尾静音淡出。最后对 5 毫秒边界做微小偏移修正，消除样本端点跳变；这不是实际游戏循环听感的验证。

火焰以低频滑音和带通噪声制造喷燃与爆裂；冰霜以非整数倍泛音、结晶音阶和短扩散尾音制造晶体共鸣；闪电以噪声脉冲、频率调制和低频雷鸣制造断续放电。常用声音变体采用固定随机种子，重复生成可复现。

冰霜与闪电 Q 文件仍是完整音色与节奏概念，尚未按游戏的真实轮数、释放时间和强化参数同步。寒域和余烬也只是一次性声音小样，不是已经制作好的持续区域音轨。后续接入前需要按实际事件拆成起手、阶段与结束声。

## 火焰 Q 单轮火墙

[单轮文件](sfx/fire_ultimate.wav) 沿用原 2.10 秒整段概念的燃烧风格，截取第一轮喷燃为 0.38 秒。原版噪声种子、缓起喷燃包络、11 Hz 起伏和第一轮低频声部继续作为声源，增加 950 Hz 平滑低通，压低刺耳的高频火噪，让音色偏低沉；末尾 55 毫秒平滑收束，再按通用导出流程处理首尾和峰值。没有内部第二轮或第三轮。保留原文件名，触发含义改为每轮火墙出现时播放一次，不按每个敌人命中重复播放。

当前 [大招定义](../../src/game/ultimates/definitions.ts) 的火墙轮间隔是 450 毫秒，单轮 WAV 为 380 毫秒，按此间隔播放时有 70 毫秒间隙。峰值从上一版约 −2.16 dBFS 收低到约 −3.74 dBFS，不代表感知响度已校准。三轮试听只是离线排布示例，不是游戏事件接入。其他 37 项主素材及五变体对比文件保持原样。检查见 [单轮火墙验证](fire-pulse-verification.json)。

## 雷电普攻与命中：电流

三个普攻改为短流、双涌、游流；两个命中改为触电、余流。以连续噪声叠加不规则快速调制形成「滋滋」电流声，保留短暂持续段，移除原来分散的尖锐放电拍点与低频冲击。双涌在中段有短暂回落，游流和余流通过起伏区分。

[雷电五版本对比](lightning_variants_comparison.wav) 依次播放三个普攻、两个命中。各时长保持 0.22/0.29/0.34/0.18/0.25 秒；普攻峰值约 −6.02 dBFS、命中约 −7.96 dBFS。E/Q 与蓄雷放电素材保持原样。

十个新素材沿用游戏正在引用的路径，刷新游戏即可加载。已检查音频格式、无削波、首尾、重复生成、对比片段与主素材一致及清单校验值，见[本轮音色验证](combat-tone-verification.json)。自然度、燃烧与电流质感仍需试听；峰值相同不代表感知响度相同。

## 冰霜 E 冰刺升起

[冰霜 E](sfx/ice_skill.wav) 从原 1.50 秒音阶式概念重做为 1.00 秒冰刺升起：先有短地面裂响，再由暗到亮的寒气摩擦逐渐抬起，五根冰刺紧密错开出地，最后细小冰晶收尾。冰晶共鸣使用非整数倍与随机频率，不按音乐音阶排列；不包含持续驻留区域的循环声音。

首根冰刺在约 25 毫秒出现，五根在约 168 毫秒内推出，寒气起势在约 125 毫秒达到中心；这些是声音内部的层次安排，尚未与实际游戏动画逐帧同步。峰值沿用约 −2.85 dBFS。文件检查见 [冰刺升起验证](ice-skill-verification.json)，实际上升感、响度与空间感仍需试听。

- 不同事件保留不同播放强度：普通命中和菜单选择较轻，E/Q、受伤与 Boss 登场更突出。没有宣称达到某个 LUFS 标准。

- 已检查 WAV 头、样本长度、非静音、无满幅削波、音效首尾近零、音乐循环端点和完整小节长度。
- 在 Codex 内置浏览器确认三段音乐与音效速览可解码播放，时长正确；切换暂停上一项、停止按钮暂停全部，检查期间无控制台错误或警告。记录见 [验证记录](verification.json)。

- 上述是文件与样本检查，没有经过可靠的听音审校；频率平衡、循环听感、耳机与手机外放效果仍待用户试听。这一版不代表专业演奏或最终混音。

## 护盾破裂打磨

[护盾破裂](sfx/shield_break.wav) 按玻璃破裂方向重新制作：起音为高频炸裂与短促玻璃板共振，随后 22 个碎片声由密到疏散落，其中 7 片带一次较轻的落地回弹。相比上一版干短碎裂，提高碎片共振的比重、亮度与延续时间，移除低频撞击滑音，让后半段保留玻璃叮落的质感。每片使用独立噪声、非整数倍共振与不规则时点，不排列旋律；碎片略向两侧散开，主裂响保持居中。全部由离线合成生成，不是真实玻璃录音。

总长从上一版 0.64 秒延长为 1 秒，以容纳碎片散落，峰值保持约 −4.01 dBFS。仍是 44.1 kHz、16 位双声道 PCM，固定随机种子可复现。已验证非静音、无满幅削波、首尾为零、重复生成一致、速览逐段样本一致，以及 HTTP 分段读取；受伤音效与其他主素材保持本轮修改前内容。检查环境及数据见[护盾破裂验证](shield-break-verification.json)。本轮未做人工听音、浏览器音频播放或手机外放验证，尚未接入游戏。

## Boss 登场短乐句

[魔核降临 · Boss 登场](sfx/boss_arrival.wav) 为 3.25 秒、单次播放的史诗感短音乐，使用离线合成的管弦乐风格音色。保持 D 小调、96 BPM、4/4 拍和 D–F–E–A–D 五音动机：主旋律由跨三个八度的铜管声部齐奏，弦乐铺底与短句增加运动感；和声按 D 小调 → A 大调 → D 小调推进。收尾前五次渐强定音鼓滚奏，在最后和弦处叠加低鼓、镲声与稍宽的扩散尾音。

仍为一小节 2.5 秒，尾音从上一版 0.5 秒增至 0.75 秒，总长 3.25 秒；最终和弦仍在 1.875 秒落下。峰值保持约 −2.50 dBFS，通过声部、音域、节奏与空间感调整史诗氛围，并非只提高导出峰值。格式为 44.1 kHz、16 位双声道 PCM，保持 `boss_arrival.wav` 路径，不循环。铜管、弦乐、定音鼓均为合成音色，不是真实乐团录音。

已验证非静音、无满幅削波、首尾为零、重复生成一致、小节加尾音长度正确、单声道合并非静音、速览逐段一致、素材清单校验值及 HTTP 分段读取。环境与数据见[Boss 登场验证](boss-arrival-verification.json)。本轮未进行人工听音、浏览器音频播放、手机外放或实战混音验证，也尚未接入 Boss 生成事件。

## 重新生成

在仓库根目录执行，需 Python 3 与 NumPy：

```sh
python3 tools/audio/render_drafts.py
python3 tools/audio/render_theme.py
python3 tools/audio/render_fire_variants.py
python3 tools/audio/render_fire_pulse.py
python3 tools/audio/render_lightning_variants.py
python3 tools/audio/render_ice_impacts.py
python3 tools/audio/render_ice_skill.py
python3 tools/audio/render_player_hurt.py
python3 tools/audio/render_shield_break.py
python3 tools/audio/render_boss_arrival.py
python3 tools/audio/make_preview.py
```

仅重新生成主题曲时执行 `render_theme.py` 与 `make_preview.py`；仅重新生成本组火焰变体时执行 `render_fire_variants.py` 与 `make_preview.py`；仅重新生成火焰 Q 时执行 `render_fire_pulse.py` 与 `make_preview.py`。若通过浏览器试听并使用段落跳转，启动支持音频分段读取的本机服务：

```sh
python3 tools/audio/serve_preview.py
```

然后访问 `http://127.0.0.1:4178/`；结束试听后在终端按 Ctrl+C 关闭服务。服务只监听本机地址，不用于公开发布。直接打开 WAV 文件也可以试听。


所有生成物仅写入本目录。音乐是无损制作文件，当前包未进行交付体积压缩；后续确认声音方向后，再选择游戏用编码和加载方式。

仅重新生成雷系普攻、命中与对比音频时，执行 `render_lightning_variants.py` 与 `make_preview.py`。

仅重新生成冰系两种命中与对比音频时，执行 `render_ice_impacts.py` 与 `make_preview.py`。

仅重新生成冰系 E 时，执行 `render_ice_skill.py` 与 `make_preview.py`。

仅重新生成护盾破裂时，执行 `render_shield_break.py` 与 `make_preview.py`；仅重新生成受伤音效与连续试听时，执行 `render_player_hurt.py` 与 `make_preview.py`。

仅重新生成 Boss 登场时，执行 `render_boss_arrival.py` 与 `make_preview.py`。
